Q911 Quick Start Guide

EXMP-Q911 EXEC-Q911 APEX-A100 Yocto · Ubuntu

This guide covers cabling, first boot, serial console and network access for a new EXEC-Q911 or APEX-A100 board — start here while the board is still in the box; it ends with a shell prompt on the device.

01Overview

Overview

The Q911 family is built around the Qualcomm® IQ-9075 SoC. The product line currently has three versions. The table below provides an overview of their differences and the items included in each packing list.

This guide focuses on the EXEC-Q911 and APEX-A100 platforms, providing an overview of their hardware and helping you get the system up and running quickly.

Each device ships with either Yocto Linux or Ubuntu pre-flashed on the UFS storage, allowing you to power on the system and log in immediately. If you need to re-flash or update the system image, please refer to the Q911 Image Flashing Guide.

EXEC-Q911 / APEX-A100 Hardware

04Prepare

Step 1: Prepare Required Items

Before you get started, please make sure you have the following items:

  • DisplayPort (DP) monitor
  • USB keyboard & mouse
  • Ethernet cable
  • USB Type-C cable
  • USB-to-TTL serial adapter
  • 60W power adapter
05Power on

Step 2: Power On

Please follow the steps below to boot the system.

  1. 1
    Please ensure that the jumper on the bottom side of the board is set to Normal mode.
    EDL mode should be used when flashing the system image.
  2. 2
    Please ensure that all boot mode DIP switches are set to ON, so the system boots from UFS.
  3. 3
    Connect the power supply and press the power button to boot the system.
06Interact

Step 3: Interact with the System

After the system boots, you can access the platform using one of the following methods:

  • DisplayPort monitor
  • SSH over Ethernet
  • ADB over USB Type-C
  • UART Debug Console

Please refer to the Q911 Image Flashing Guide: Boot into the System for detailed instructions on flashing the image. For the networking steps Ubuntu needs on first boot, see First-Boot Network Setup.

Whether a login is required depends on the operating system and the access method:

First-Boot Network Setup (Ubuntu)

Ubuntu does not bring up Ethernet on first boot. Before any network operation, install the iq-ubuntu*.deb post-flash networking package. The install steps are in the Debian package part of iQ-ubuntu__manifest (no longer maintained since v2.5.1; merged into meta-iQ__manifest).

01 DP DISPLAY

Interact with the System Using a DP Display

If you are accessing the system using a DP display, please follow the steps below to set it up.

  1. 1
    Connect the DP display and USB keyboard/mouse. Then, connect the power cable and press the power button to boot the system.
  2. 2
    After the device boots up, you should see the output displayed on the DisplayPort (DP) monitor.
    • In Yocto Linux, you can click the icon in the upper-left corner to open the terminal.
    • In Ubuntu, you can interact with the system just as you would on a standard amd64 Ubuntu installation.
02 SSH · ETHERNET

Interact with the System Using SSH over Ethernet

If you are accessing the system using SSH to interact with the system, please follow the steps below to set it up. If Ubuntu does not have network connectivity, install the iq-ubuntu*.deb package. See First-Boot Network Setup.

Please connect an Ethernet cable and ensure that the device is reachable over the network. Then, connect the power cable and press the power button to boot the system. After the device boots up, you can access the device via SSH from any machine on the same network.

03 ADB · USB-C

Interact with the System Using ADB over USB Type-C

If you are accessing the system using adb to interact with the system, please follow the steps below to set it up. The USB Type-C port on both platforms supports Flash / ADB.

ADB is not supported on Ubuntu. Use DP, SSH, or UART instead.

Connect the USB Type-C cable between the host and the device. Then, connect the power cable and press the power button to boot the system. After the device boots up, use the following commands on the host to verify the device connection and open an interactive shell. You can run Linux commands from the adb shell — the example below checks the BSP version.

{{ cb.fname }} bash
04 UART · 115200 8N1

Interact with the System Using UART Debug Console

If you are accessing the system using UART debug console to interact with the system, please follow the steps below to set it up.

You can refer to the Qualcomm guide on setting up a debug UART for detailed instructions on how to connect using minicom.

Please connect the USB-to-TTL serial adapter to the UART pins on the bottom side of the board. Then, connect the power cable and press the power button to boot the system. After the device boots up, you will see a screen similar to the one shown below.
