GenieX: Run Your Own LLM/VLM on the Platform

SDKGenieXLLMVLMOpenAI-compatible

GenieX is Qualcomm's on-device generative AI inference runtime. It runs language models (LLMs) and vision-language models (VLMs) locally on the Hexagon NPU, the Adreno GPU or the CPU, with no cloud connection. This guide shows how to use it from the CLI, as an OpenAI-compatible server, and from Python.

GenieX powers the iQS-VLM application. See it running with a live camera there, or chat with it through Open WebUI in the iQS-VLM SDK.
Requires BSP v2.5.0 or later.

Runtimes

GenieX has one SDK and two runtimes. Pick the runtime that matches your model:

RuntimeModelsBackends
llama.cppGGUF models from Hugging Face, ModelScope or Docker HubNPU, GPU, CPU
QAIRT (Qualcomm AI Engine Direct)Pre-compiled bundles from Qualcomm AI HubNPU only, fastest on the NPU

For GGUF models, choose the Q4_0 precision for the best NPU support. The full model list is in Supported models.

Use GenieX from the CLI

Start an interactive chat with a model. GenieX downloads the model on first use.

Run a QAIRT model from Qualcomm AI Hub on the NPU:

{{ cb2.fname }} bash

Run a GGUF model through llama.cpp on the NPU:

{{ cb3.fname }} bash

To ask a VLM about an image, put the image's full path in your prompt, for example Describe the image. Image: /full/path/photo.jpg.

Useful commands and options:

CommandWhat it does
geniex pull <model>Download a model without starting a chat
geniex listList the downloaded models
geniex model listList the QAIRT models available for this chipset
geniex infer <model> --compute gpuRun a llama.cpp model on npu (default), gpu or cpu
geniex infer <model> -s "<prompt>"Set a system prompt
geniex remove <model>Delete a downloaded model

All commands and options are in the CLI reference.

Use GenieX as a Server

geniex serve starts an OpenAI-compatible server, so any OpenAI client can talk to the model without code changes. It does not download models, so pull the model first:

{{ cb4.fname }} bash

The server listens on http://127.0.0.1:18181. Open that address in a browser on the platform to try the API in the built-in Swagger UI. It provides:

  • POST /v1/chat/completions
  • POST /v1/completions
  • GET /v1/models

Send it a request from another terminal:

{{ cb5.fname }} bash

Or use the OpenAI Python client (python3 -m pip install openai):

{{ cb6.fname }} python

To send an image to a VLM, add an image_url part to the message. The URL can be a local file path, an HTTP(S) URL or a base64 data URL:

{{ cb7.fname }} python

More options are in the local server guide.

Use GenieX from Python

Install the Python SDK (ARM64 Python 3.10 or later):

{{ cb8.fname }} bash

The API follows Hugging Face transformers. Create example.py:

{{ cb9.fname }} python

Run it with python3 example.py.

To ask a VLM about an image, download a sample image:

{{ cb10.fname }} bash

Then pass it in the message and to generate:

{{ cb11.fname }} python

The full API is in the Python API reference.
